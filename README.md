# E-Commerce-Web-Application
A lightweight, full-stack E-Commerce web application built with Python (Flask) and MySQL featuring user authentication, role-based access control, session-based cart management, and RESTful admin APIs.


Key Features
🔐 User Authentication & RBAC: Secure user registration, login, and session-based logout with role-based access control (User vs. Admin).

🛍️ Product Catalog & Cart Management: Dynamic product display and session-persistent shopping cart.

💳 Order Processing: Checkout system tracking order status and order histories per user.

🛠️ Admin REST APIs: Protected API endpoints allowing administrators to view, add, or delete products and monitor all user orders.

🗄️ Relational Database Design: Normalised MySQL schema linking users, products, and orders via foreign key constraints.

Tech Stack
Backend: Python 3, Flask

Database: MySQL (mysql-connector-python)

Frontend: HTML5, Jinja2 Templates, CSS3

API Format: JSON
